# mc

Midnight Commander — двухпанельный файловый менеджер в терминале.

## Запуск

```bash
mc
```

## Навигация

```bash
# Перемещение — стрелки
# Переключение панели — Tab
# Войти в каталог — Enter
# Выйти из каталога — Esc, затем O или стрелка вверх
# Быстрый поиск файла — Ctrl+S
# Отметить файл — Insert
```

## Просмотр и редактирование

```bash
# Просмотр файла — F3
# Редактирование файла — F4
# Копирование — F5
# Перемещение/переименование — F6
# Удаление — F8
# Меню — F9
```

## Поиск

```bash
# Поиск файла — Esc, затем ?
# Или через меню: F9 → Command → Find file
```

## Полезные возможности

```bash
# Сравнение каталогов в двух панелях
# F9 → Command → Compare directories

# Быстрый переход к часто используемым путям
# F9 → Command → Directory hotlist

# Просмотр логов с подсветкой
# F3 на .log файле
```
