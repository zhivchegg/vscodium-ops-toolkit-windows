# less

Постраничный просмотр файлов и логов с поиском.

## Основные примеры

```bash
# Просмотр файла
less app.log

# Следовать за новыми строками (аналог tail -f)
less +F app.log

# Открыть с конца файла
less +G app.log

# Показать номера строк
less -N app.log
```

## Навигация

```bash
# Вниз/вверх на строку — стрелки или J/K
# Вниз/вверх на страницу — Space / B
# В начало/конец файла — G / Shift+G
# Поиск — /pattern, следующее совпадение — N, предыдущее — Shift+N
# Поиск без учёта регистра — /pattern затем Ctrl+I
# Выйти — Q
```

## Поиск по логам

```bash
# Открыть файл и сразу перейти к первому вхождению
less +/ERROR app.log

# Инвертировать фильтр (показывать только строки без паттерна)
less -I +/ERROR app.log
```

## Алиасы в сборке

В `.bashrc` задано:

```bash
LESS='-R -X -F -i -K'
```

Это означает:
- `-R` — корректное отображение ANSI-цветов
- `-X` — не очищать экран после выхода
- `-F` — выход, если файл помещается на один экран
- `-i` — поиск без учёта регистра
- `-K` — разрешить прерывание по Ctrl+C
