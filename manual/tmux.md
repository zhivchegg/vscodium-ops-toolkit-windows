# tmux

Терминальный мультиплексор: несколько окон и панелей в одной сессии.

## Сессии

```bash
# Создать новую сессию
tmux new -s logs

# Подключиться к существующей
tmux attach -t logs

# Список сессий
tmux ls

# Отключиться от сессии (не закрывая её)
# Нажать Ctrl+B, затем D

# Убить сессию
tmux kill-session -t logs
```

## Окна

```bash
# Создать окно: Ctrl+B, затем C
# Переключиться между окнами: Ctrl+B, затем N или P
# Переименовать окно: Ctrl+B, затем ,
# Закрыть окно: Ctrl+B, затем &
```

## Панели

```bash
# Разделить по вертикали: Ctrl+B, затем %
# Разделить по горизонтали: Ctrl+B, затем "
# Перемещаться между панелями: Ctrl+B, затем стрелка
# Увеличить/уменьшить панель: Ctrl+B, затем Ctrl+стрелка
# Закрыть панель: Ctrl+B, затем X или ввести exit
```

## Практика для мониторинга

```bash
tmux new -s logs
# В первой панели: tail -f /var/log/app.log
# Во второй: tail -f /var/log/nginx/access.log
# В третьей: htop
```
