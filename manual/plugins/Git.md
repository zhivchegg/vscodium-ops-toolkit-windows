# Git

В сборке установлены три плагина: **GitLens**, **Git Graph** и **Git History**. Они дополняют встроенный Git VSCodium.

## Что проверить при инциденте

1. Кто последний менял файл? Когда?
2. Есть ли незакоммиченные изменения?
3. Какая ветка сейчас активна?
4. Был ли откат или force-push?
5. Можно ли восстановить потерянный коммит?

## GitLens

Показывает аннотации прямо в редакторе:
- автор и время последнего изменения строки
- ссылка на коммит
- история изменений файла

Команды:
- `Ctrl+Shift+P` → `GitLens: Open File History`
- `Ctrl+Shift+P` → `GitLens: Copy Absolute URL to File` (если настроен remote)

## Git Graph

Визуальное представление веток и коммитов.

Открыть: `Ctrl+Shift+P` → `Git Graph: View Git Graph`.

Возможности:
- посмотреть историю всех веток
- сравнить два коммита
- создать/переключить/слить ветки
- cherry-pick

## Git History

Просмотр истории отдельного файла.

Открыть: в проводнике нажать правой кнопкой на файл → `Git: View File History`.

## Быстрые команды в терминале

```bash
# Текущий статус
git status

# Кто менял строки файла
git blame -L 10,30 script.sh

# История с графом
git log --oneline --graph --all -20

# Разница с предыдущим коммитом
git diff HEAD~1

# Статистика изменений
git diff HEAD~1 --stat

# Найти коммит, в котором появился баг
git bisect start
```

## Поиск по истории

```bash
# Найти коммит по тексту в коде
git log -S "function_name" --oneline

# Найти коммит по сообщению
git log --grep="fix timeout" --oneline

# Кто удалил файл
git log --diff-filter=D --summary | grep delete
```

## Восстановление после ошибок

```bash
# Показать историю всех операций (для восстановления коммитов)
git reflog

# Восстановить коммит по хешу из reflog
git checkout HEAD@{3}

# Отменить последний коммит, сохранив изменения
git reset --soft HEAD~1

# Полностью отменить последний коммит
git reset --hard HEAD~1
```

## Шаблон расследования инцидента

```bash
# 1. Определить затронутый файл
FILE="src/api.py"

# 2. Кто последний менял
git log -1 --format='%h %an %ad %s' -- "$FILE"

# 3. Что именно изменилось
git show HEAD -- "$FILE"

# 4. Если нужно откатить
git revert HEAD
```

## Важно

- Перед revert убедитесь, что не потеряете нужные изменения.
- Force-push (`git push -f`) ломает историю для команды — используйте только в крайнем случае.
- `git reset --hard` необратим для незакоммиченных изменений — используйте `git stash` или копию.
