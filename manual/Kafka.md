# Kafka for VS Code

Плагин для просмотра топиков, сообщений и конфигурации Kafka.

## Настройка подключения

В плагине обычно требуется указать:
- `bootstrap.servers`: `kafka-broker:9092`
- SASL/TLS настройки (при необходимости)

## Базовые проверки без Kafka CLI

Проверка доступности брокера:

```bash
nc -zv kafka-broker 9092
```

Проверка TLS:

```bash
openssl s_client -connect kafka-broker:9093 -servername kafka-broker </dev/null
```

Проверка DNS:

```bash
nslookup kafka-broker
```

## Просмотр сообщений в плагине

1. Подключитесь к кластеру.
2. Разверните список топиков.
3. Выберите топик → просмотр последних сообщений.
4. Можно фильтровать по ключу или значению.

## Советы

- Для production обычно требуется SASL/SSL.
- Если плагин не подключается, сначала проверьте `nc -zv`.
- Kafka CLI (`kcat` и официальные бинарники) не включены в сборку из-за отсутствия стабильных Windows-релизов.
