# mc

Midnight Commander — двухпанельный файловый менеджер в терминале. Удобен для просмотра логов, сравнения каталогов и быстрых операций с файлами.

## Что проверить при инциденте

1. Где находятся нужные лог-файлы?
2. Есть ли большие файлы, занимающие диск?
3. Нужно ли сравнить конфигурации до и после инцидента?

## Запуск

```bash
mc
```

## Навигация

| Клавиша | Действие |
|---|---|
| `↑↓←→` | Перемещение |
| `Tab` | Переключение панели |
| `Enter` | Войти в каталог / открыть файл |
| `Ctrl+S` | Быстрый поиск файла |
| `Insert` | Отметить файл |
| `Alt+.` | Показать/скрыть скрытые файлы |

## Основные операции

| Клавиша | Действие |
|---|---|
| `F2` | Пользовательское меню |
| `F3` | Просмотр файла |
| `F4` | Редактирование |
| `F5` | Копирование |
| `F6` | Перемещение/переименование |
| `F8` | Удаление |
| `F9` | Меню |
| `F10` | Выход |

## Поиск файлов

```bash
# F9 → Command → Find file
# Или
Esc → ?
```

Можно искать по имени или содержимому.

## Сравнение каталогов

```bash
# F9 → Command → Compare directories
```

Покажет файлы, отличающиеся между левой и правой панелью.

## Избранные пути (Directory hotlist)

```bash
# F9 → Command → Directory hotlist
# Или Ctrl+\
```

Добавьте часто используемые пути для быстрого перехода.

## Просмотр больших логов

1. Найдите файл через `Ctrl+S`.
2. Нажмите `F3` — откроется встроенный просмотрщик.
3. Используйте `F7` для поиска внутри файла.

## Практический пример: поиск логов за сегодня

```bash
# F9 → Command → Find file
# Шаблон имени: *.log
# Содержимое: ERROR
# Путь: /var/log
```

## Подводные камни

- mc может не корректно отображать символы Unicode без настройки locale.
- При удалении файлов через mc они удаляются сразу, не в корзину.
- Для копирования прав root используйте `sudo mc` (если доступно).
- Встроенный редактор `mcedit` (F4) удобен, но может конфликтовать с настройками VSCodium.
- Панели можно переключать в режимы отображения через `F9 → Left/Right → List mode`.
