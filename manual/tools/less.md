# less

Постраничный просмотр файлов и логов с поиском. В сборке настроен оптимально для работы с логами.

## Что проверить при инциденте

1. В какой момент времени началась проблема?
2. Есть ли ошибки или исключения?
3. Что происходило до и после ошибки?
4. Не слишком ли большой файл для less?

## Основные примеры

```bash
# Просмотр файла
less app.log

# Следовать за новыми строками (аналог tail -f)
less +F app.log

# Открыть с конца файла
less +G app.log

# Показать номера строк
less -N app.log

# Открыть и сразу найти строку
less +/ERROR app.log
```

## Навигация

| Клавиша | Действие |
|---|---|
| `↓` / `j` | Строка вниз |
| `↑` / `k` | Строка вверх |
| `Space` / `f` | Страница вниз |
| `b` | Страница вверх |
| `g` | Начало файла |
| `G` | Конец файла |
| `/pattern` | Поиск вперёд |
| `?pattern` | Поиск назад |
| `n` / `N` | Следующее/предыдущее совпадение |
| `m` + буква | Поставить закладку |
| `'` + буква | Перейти к закладке |
| `&pattern` | Показать только строки с паттерном |
| `q` | Выход |

## Поиск по логам

```bash
# Поиск без учёта регистра (уже включено в LESS)
less +/error app.log

# Поиск с регулярным выражением
less +/"timeout|connection refused" app.log

# Показать только строки с ERROR (фильтр)
less app.log
# затем нажать &ERROR

# Для фильтра с grep:
grep -v INFO app.log | less
```

## Алиасы в сборке

В `.bashrc` задано:

```bash
LESS='-R -X -F -i -K'
```

Значение:
- `-R` — корректное отображение ANSI-цветов
- `-X` — не очищать экран после выхода
- `-F` — выход, если файл помещается на один экран
- `-i` — поиск без учёта регистра
- `-K` — разрешить прерывание по Ctrl+C

## Практический пример: расследование инцидента

```bash
# Открыть лог на последней строке
less +G app.log

# Найти ближайшую ошибку выше
?ERROR

# Посмотреть контекст вокруг
# Нажимайте N для перехода к предыдущим ошибкам

# Поставить закладку на текущей строке
ma

# Вернуться к закладке позже
'a
```

## Подводные камни

- Для файлов >1 ГБ less всё ещё работает, но поиск может быть медленным.
- `less +F` не обновляется автоматически — нажмите `Shift+F`, чтобы продолжить следовать.
- Если less завис на бинарном файле, нажмите `q` — флаг `-K` позволяет прервать по Ctrl+C.
- Фильтр `&pattern` действует только на отображение, исходный файл не меняется.
