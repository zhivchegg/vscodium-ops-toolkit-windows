# sed

Потоковый редактор для замены, удаления и извлечения текста. Используется для очистки и подготовки данных.

## Что проверить при инциденте

1. Нужно ли удалить чувствительные данные из лога перед передачей?
2. Нужно ли нормализовать формат логов?
3. Нужно ли извлечь определённые строки из большого файла?
4. Нужно ли объединить или разделить строки?

## Замена текста

```bash
# Простая замена (первое вхождение в строке)
sed 's/foo/bar/' app.log

# Замена всех вхождений в строке
sed 's/foo/bar/g' app.log

# Замена без учёта регистра
sed 's/error/ERROR/gi' app.log

# Замена только в строках с паттерном
sed '/ERROR/s/foo/bar/g' app.log

# Расширенные регулярные выражения
sed -E 's/[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}/IP/g' app.log
```

## Удаление строк

```bash
# Удалить пустые строки
sed '/^$/d' app.log

# Удалить строки с DEBUG
sed '/DEBUG/d' app.log

# Удалить строки 1–10
sed '1,10d' app.log
```

## Извлечение строк

```bash
# Строки 5–20
sed -n '5,20p' app.log

# Строки с паттерном
sed -n '/ERROR/p' app.log

# Строки между двумя паттернами
sed -n '/START/,/END/p' app.log

# Каждая вторая строка
sed -n '1~2p' app.log
```

## Объединение и разделение строк

```bash
# Объединить каждые две строки в одну через пробел
sed 'N;s/\n/ /' app.log

# Добавить пустую строку после каждой строки
sed G app.log
```

## Редактирование файла на месте

```bash
# С резервной копией
sed -i.bak 's/foo/bar/g' app.log

# Без резервной копии
sed -i 's/foo/bar/g' app.log
```

## Очистка данных

```bash
# Убрать ANSI-цвета
sed 's/\x1b\[[0-9;]*m//g' app.log

# Заменить разделитель, если в паттерне есть /
sed 's#C:/Users/foo#D:/data#g' app.log

# Маскировать токены
sed -E 's/(token=)[^&]*/\1***/g' app.log
```

## Практический пример: подготовка лога к отправке

```bash
# Оставить только строки с ERROR, убрать IP, замаскировать токены
sed -n '/ERROR/p' app.log | \
  sed -E 's/[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}/IP/g' | \
  sed -E 's/(token=)[^&]*/\1***/g' > error-report.log
```

## Подводные камни

- `sed -i` на месте изменяет файл — всегда делайте копию перед массовой заменой.
- В MSYS2 sed интерпретирует `\x1b` для ANSI-цветов; если не работает, используйте `printf` или Perl.
- Регулярные выражения sed — базовые; для сложных операций используйте `sed -E`.
- Для задач с условной логикой проще использовать awk или Python.
- `sed` работает построчно — для многострочных операций используйте `N` или другие инструменты.
