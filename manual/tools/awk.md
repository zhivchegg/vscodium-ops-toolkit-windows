# awk

Обработка текстовых данных по столбцам, подсчёты и простые отчёты. Особенно полезен для анализа логов и CSV.

## Что проверить при инциденте

1. Какой разделитель используется в файле (пробел, таб, запятая)?
2. Какие столбцы содержат нужные данные?
3. Нужен ли подсчёт, сумма или группировка?
4. Есть ли пустые или неполные строки?

## Основные примеры

```bash
# Вывести первый и третий столбец
awk '{print $1, $3}' app.log

# Указать разделитель (запятая)
awk -F',' '{print $2}' data.csv

# Фильтр по значению столбца
awk '$3 == "ERROR" {print $0}' app.log

# Числовое сравнение
awk '$2 > 500 {print $1, $2}' app.log

# Регулярное выражение в столбце
awk '$5 ~ /timeout/ {print $0}' app.log
```

## Блоки BEGIN и END

```bash
# Инициализация перед обработкой и вывод после
awk 'BEGIN {print "Start"} {print $0} END {print "Done"}' app.log

# Печать заголовка CSV
awk -F',' 'BEGIN {print "IP,STATUS"} {print $1","$4}' access.log
```

## Подсчёты и агрегации

```bash
# Количество строк
awk 'END {print NR}' app.log

# Строки с паттерном
awk '/ERROR/ {n++} END {print n}' app.log

# Сумма по столбцу
awk '{sum += $2} END {print sum}' app.log

# Среднее и максимум
awk '{sum += $2; n++; if ($2 > max) max = $2} END {print "avg:", sum/n, "max:", max}' app.log
```

## Группировка

```bash
# Подсчёт вхождений по столбцу
awk '{count[$3]++} END {for (k in count) print count[k], k}' app.log | sort -rn

# Сумма по группе
awk '{sum[$1] += $2} END {for (k in sum) print k, sum[k]}' app.log

# Топ IP по количеству запросов
awk '{ip[$1]++} END {for (i in ip) print ip[i], i}' access.log | sort -rn | head
```

## Полезные переменные

| Переменная | Значение |
|---|---|
| `$0` | Вся строка |
| `$1, $2, ...` | Поля по порядку |
| `NF` | Количество полей в строке |
| `NR` | Номер строки |
| `FS` | Разделитель полей |
| `OFS` | Разделитель выходных полей |
| `RS` | Разделитель записей |

## CSV с кавычками

Для CSV, где поля могут содержать запятые:

```bash
# FPAT — разделение по шаблону поля
awk 'BEGIN {FPAT="([^,]*)|(\"[^\"]+\")"} {print $1, $2}' data.csv
```

## Практический пример: анализ access.log

```bash
# Предположим формат: IP METHOD PATH STATUS SIZE
# 192.168.1.1 GET /api/users 200 1234

# Статусы по частоте
awk '{status[$4]++} END {for (s in status) print status[s], s}' access.log | sort -rn

# Средний размер ответа для 5xx
awk '$4 >= 500 {sum += $5; n++} END {if (n) print sum/n}' access.log

# Медленные запросы (если есть столбец времени)
awk '$6 > 1000 {print $0}' access.log

# Пропустить пустые строки
awk 'NF > 0 {print $0}' app.log
```

## Подводные камни

- По умолчанию awk сжимает пробелы — если нужны пустые поля, используйте `-F'[ \t]+'`.
- Переменные не нужно объявлять, но неинициализированные переменные в арифметике равны 0.
- Для работы с CSV, содержащими запятые внутри кавычек, стандартный awk не подходит — используйте `FPAT` или Python.
- Порядок обхода ассоциативного массива не гарантирован — сортируйте вывод через `sort`.
